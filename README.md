
【核心功能】
将你的书签可视化进行管理， 定位书签地址，双搜索栏、拖拽整理、去重、导入导出、,支持与浏览器书签实时互通。完全私有化的本地书签管理器, 不收集任何用户数据, 即插即用, 完全不用担心隐私问题.

• 可调大小侧边栏：Chrome/Edge 原生 sidePanel，可拖宽、可停靠；Firefox 走 sidebar_action
• 双搜索栏：上方搜书签（名称/网址/描述/标签），下方选搜索引擎搜网页，支持百度、Google、Bing 等 40+ 引擎
• 分层分类导航：一级/二级/三级文件夹分层换行展示，可手动收起展开，拖拽到分类标签即可跨文件夹移动
• 重复清理：一键扫描全库重复书签，按网址归并
• 导入导出：支持本应用备份 JSON、Firefox 书签 JSON、浏览器导出 HTML（Netscape）
• 深浅主题 + 紧凑/宽松双密度
• 本地存储不上传服务器

【新增功能 v1.4.2】
• 独立空白模式：新装默认空白独立存储，与浏览器书签完全隔离；可在配置中一键切换为同步模式
• 自定义快捷键：1 切换侧栏 / 2 新标签页打开 / / 聚焦搜索；全局快捷键 Alt+1 / Alt+2
• 像素级图标验证：icon.horse + Yandex 双 CORS 源 + canvas 像素验证，根治图标不显示问题
• 捐助弹窗只展示作者收款码

【数据安全】
• 独立模式：数据存在扩展 storage.local，不上传任何服务器
• 同步模式：直接读写浏览器书签，实时互通
• 可随时导出 JSON / HTML 备份


## 隐私政策

### 数据收集
本扩展不收集任何用户个人数据。

### 数据存储
- 书签数据存储在浏览器本地（chrome.storage.local / localStorage）
- 不上传到任何服务器

### 权限说明
- bookmarks：读写浏览器书签（仅同步模式启用时）
- storage：存储扩展配置和独立模式书签数据
- sidePanel：打开侧边栏
- favicon：获取网站图标
- host_permissions：访问 icon.horse / Yandex 等 favicon 服务

### 第三方服务
仅用于获取网站图标：
- icon.horse
- favicon.yandex.net
- icons.duckduckgo.com
